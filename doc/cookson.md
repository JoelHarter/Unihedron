# The Cookson Solids

**Discovered by Arthur J Cookson in 2026**

The **Cookson solids** are a family of closed, symmetric, spherical polyhedra generated by projecting the vertices of non-triangular Catalan solids onto a unit sphere, and subsequently subdividing any resulting non-planar faces along internal creases to restore strict three-dimensional planarity.

---

## Geometric Construction & Mechanism

1. **Catalan Vertex Projection**:
   Take a Catalan solid with non-triangular faces (such as the Rhombic Dodecahedron, Rhombic Triacontahedron, Deltoidal Icositetrahedron, Deltoidal Hexecontahedron, Pentagonal Icositetrahedron, or Pentagonal Hexecontahedron).
2. **Radial Normalization**:
   Project each vertex $\mathbf{v}$ radially outward to lie on the unit sphere:
   $$\mathbf{v}' = R \cdot \frac{\mathbf{v}}{\|\mathbf{v}\|}$$
3. **Planar Restoration via Convex Hull / Creasing**:
   Because projecting quadrilateral or pentagonal facets onto a sphere pushes their midpoints inward relative to their vertices, the original faces lose planarity. The Cookson solid is obtained by taking the convex hull of these projected spherical vertices, which automatically subdivides the non-planar faces along internal creases into planar facets (triangles and isosceles trapezoids).

In Unihedron, this is computed constructively:

```julia
cookson(P::Polyhedron; radius=1.0) = convex_hull([radius * (v / norm(v)) for v in P.v]; merge_coplanar=true)
```

## Solid Details

### C1: Trigonal Octasphere
* **Polygon Root**: Trigonal
* **Symmetry**: Octasphere
* **Parent Catalan**: Rhombic Dodecahedron ($V=14, F=12$ rhombi)
* **Geometry**: Each rhombus is creased along its short diagonal into 2 planar triangles, yielding 24 triangles.

### C2: Trigonal Icosasphere
* **Polygon Root**: Trigonal
* **Symmetry**: Icosasphere
* **Parent Catalan**: Rhombic Triacontahedron ($V=32, F=30$ rhombi)
* **Geometry**: Each golden rhombus is creased along its short diagonal into 2 planar triangles, yielding 60 triangles.

### C3: Bitrigonal Octasphere
* **Polygon Root**: Bitrigonal
* **Symmetry**: Octasphere
* **Parent Catalan**: Deltoidal Icositetrahedron ($V=26, F=24$ kites)
* **Geometry**: Each kite is creased into 2 planar triangles, yielding 48 triangles.

### C4: Bitrigonal Icosasphere
* **Polygon Root**: Bitrigonal
* **Symmetry**: Icosasphere
* **Parent Catalan**: Deltoidal Hexecontahedron ($V=62, F=60$ kites)
* **Geometry**: Each kite is creased into 2 planar triangles, yielding 120 triangles.

### C5: Gyrotrapezotrigonal Octasphere
* **Polygon Root**: Gyrotrapezotrigonal
* **Symmetry**: Octasphere
* **Parent Catalan**: Pentagonal Icositetrahedron ($V=38, F=24$ chiral pentagons)
* **Geometry**: Each irregular pentagon is creased into 1 planar isosceles trapezoid and 1 planar triangle, yielding 24 trapezoids and 24 triangles.

### C6: Gyrotrapezotrigonal Icosasphere
* **Polygon Root**: Gyrotrapezotrigonal
* **Symmetry**: Icosasphere
* **Parent Catalan**: Pentagonal Hexecontahedron ($V=92, F=60$ chiral pentagons)
* **Geometry**: Each irregular pentagon is creased into 1 planar isosceles trapezoid and 1 planar triangle, yielding 60 trapezoids and 60 triangles.

## Julia API Usage

### 1. Accessing Solids
```julia
using Unihedron

# By index (1 to 6) or shorthand symbol (:C1 to :C6)
c1 = cookson(1)      # or cookson(:C1)
c5 = cookson(:C5)    # C5: Gyrotrapezotrigonal Octasphere
c6 = cookson(:C6)    # C6: Gyrotrapezotrigonal Icosasphere

# By official constructor names
P1 = trigonal_octasphere()
P2 = trigonal_icosasphere()
P3 = bitrigonal_octasphere()
P4 = bitrigonal_icosasphere()
P5 = gyrotrapezotrigonal_octasphere()
P6 = gyrotrapezotrigonal_icosasphere()

# Query metadata
meta = cookson_info(:C5)
println(meta.name)            # "Gyrotrapezotrigonal Octasphere"
println(meta.parent_catalan)  # "Pentagonal Icositetrahedron"
```

### 2. General Cookson Operator
You can apply the `cookson` operator to any input polyhedron:
```julia
# Project any custom solid onto a unit sphere with planar crease restoration:
custom_cookson = cookson(rhombic_triacontahedron(); radius=2.0)
```

### 3. Visualization & Shading
```julia
using GLMakie

# Interactive 3D visualization:
viz(:C5; color_by_face_size=true)
viz(:C6; color_by_face_size=true)
```

### 4. Congruent Face Analysis
```julia
# Detect face types on C5 (24 trapezoids and 24 triangles):
counts = face_type_counts(cookson(:C5))
# Dict(1 => 24, 2 => 24)
```
